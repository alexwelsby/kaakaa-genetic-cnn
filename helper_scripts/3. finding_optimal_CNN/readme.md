This directory has two branches:
- cgp-cnn code, with the output from Colab. I ran an experimental run with the Ferreira great tits dataset, as well as one with the kaakaa dataset.
- the 'benchmark CNN' VGG-19, which later became the only CNN in the experiment. The VGG-19 training code is copied heavily from (Ferreira's Bird_individualID)[https://github.com/AndreCFerreira/Bird_individualID/blob/master/Train_CNN/TRAIN_CNN.ipynb], as I was trying to reproduce Ferreira's results (to some extent - the dataset is different...)
